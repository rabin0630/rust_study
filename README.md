# rust_study

Rust の学習用リポジトリ。

[The Rust Programming Language（通称 The Book）](https://doc.rust-lang.org/book/)
（[日本語版](https://doc.rust-jp.rs/book-ja/)）を読みながら、手を動かして書いたコードを置いていく。

## 進め方

- The Book の章ごとに写経・実験する
- 気づいたことやハマったところはメモとして残す
